# Clearline 7

**Multi‑edition design token system** for building consistent, emotionally resonant UIs.  
Clearline 7 provides a parser + distributor pipeline that outputs tokens for both **Tailwind v4** and legacy CSS, enabling scalable design across multiple editions.

## ✨ Editions
- **Federal** – structured, authoritative palette
- **Clerical** – calm, document‑driven theme
- **Tech** – modern, high‑contrast system
- **Wiki** – collaborative, knowledge‑sharing style

## 📂 Repo Structure
- `editions/` → config files for each edition
- `src/` → parser + component logic
- `public/` → static assets (icons, previews)
- `clearline7_multiEdition.tsx` → prototype landing page
- `token-map.png` → visual reference of token mapping
